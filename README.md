# 🎟️ Sistema de Venda de Ingressos

Sistema de linha de comando em Python para gestão de venda de ingressos de eventos, desenvolvido como projeto da disciplina **MI-Algoritmos** (Engenharia de Computação — UEFS), 1° projeto da faculdade.

##  Funcionalidades

- **Configuração flexível do evento**: quantidade de ingressos, valor base, meia-entrada, descontos especiais e cortesias
- **Vendedores comuns e comissionados**: suporte a até 2 grupos de vendedores com comissão automática a cada N ingressos vendidos
- **Tipos de ingresso**: inteira, meia-entrada (com comprovação: estudante/idoso/outro), desconto especial e cortesia
- **Controle de estoque**: impede venda além da quantidade de ingressos disponíveis
- **Relatório final completo**:
  - Total de ingressos emitidos e não emitidos por categoria
  - Arrecadação total e por tipo de ingresso
  - Desempenho por grupo de vendedores comissionados
  - Tipo de ingresso mais vendido
  - Média de idade dos compradores

##  Como executar

```bash
python ingressos.py
```

Requer apenas **Python 3** — sem dependências externas.

## 🛠️ Tecnologias

- Python 3 (estruturas de repetição, condicionais e validação de entrada)

##  Contexto acadêmico

Projeto desenvolvido individualmente para a disciplina MI-Algoritmos, com foco em lógica de programação, controle de fluxo e validação de dados de entrada.
